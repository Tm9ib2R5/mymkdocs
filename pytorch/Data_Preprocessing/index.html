为了能⽤深度学习来解决现实世界的问题，我们经常从预处理原始数据开始，⽽不是从那些准备好的张量格 式数据开始。在Python中常⽤的数据分析⼯具中，我们通常使⽤pandas软件包。像庞⼤的Python⽣态系统中 的许多其他扩展包⼀样，pandas可以与张量兼容。本节我们将简要介绍使⽤pandas预处理原始数据，并将原 始数据转换为张量格式的步骤。后⾯的章节将介绍更多的数据预处理技术。

import os
import pandas as pd
import torch

# 创建目录和文件
os.makedirs(os.path.join('..', 'data'), exist_ok=True)
data_file = os.path.join('..', 'data', 'house_tiny.csv')
with open(data_file, 'w') as f:
    f.write('NumRooms,Alley,Price\n')
    f.write('NA,Pave,127500\n')
    f.write('2,NA,106000\n')
    f.write('4,NA,178100\n')
    f.write('NA,NA,140000\n')

# 读取数据
data = pd.read_csv(data_file)
print("原始数据：")
print(data)

# 分离输入和输出
inputs, outputs = data.iloc[:, 0:2], data.iloc[:, 2]

# 处理输入缺失值
inputs['NumRooms'] = pd.to_numeric(inputs['NumRooms'], errors='coerce')
inputs['NumRooms'] = inputs['NumRooms'].fillna(inputs['NumRooms'].mean())

# 让 Alley 的缺失值保持为 float('nan')，不要填字符串
inputs['Alley'] = inputs['Alley'].replace('NA', float('nan'))  # 如果原始是字符串 NA
inputs = pd.get_dummies(inputs, dummy_na=True)                 # 只会生成 Alley_nan（bool）

# 强制转数值
inputs = inputs.astype(float)          # 关键一步，确保全部为 float32
X = torch.tensor(inputs.values, dtype=torch.float32)
Y=torch.tensor(outputs.values, dtype=torch.float32)
print(inputs.dtypes)   # 应该全是 float64
print(inputs.values.dtype)  # 应该是 float64
print(X,Y)
