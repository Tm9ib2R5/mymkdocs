快速开始

1

安装 MkDocs

使用 pip 安装 MkDocs：

pip install mkdocs
2

创建新项目

使用以下命令创建新的文档项目：

mkdocs new my-project
cd my-project
3

预览文档

启动开发服务器实时预览文档：

mkdocs serve

然后在浏览器中访问 http://localhost:8000

4

构建站点

构建静态站点以进行部署：

mkdocs build

这将在 site 目录中生成完整的静态网站。
