    MkDocs 文档中心 欢迎来到 MkDocs 文档中心！MkDocs 是一个快速、简单且完全免费的静态站点生成器，专门用于构建项目文档。文档源文件使用 Markdown 编写，通过单个 YAML 配置文件进行配置。

    https://www.mkdocs.org/img/icon.png

    ✨ 主要特性 🚀 快速构建 - 基于 Python 的高效构建过程，快速生成静态站点

    🎨 美观主题 - 内置多个精美主题，支持完全自定义

    🔍 即时搜索 - 内置全文搜索功能，无需服务器端处理

    📱 响应式设计 - 在移动设备上完美展示

    🔧 高度可扩展 - 支持丰富的插件生态系统

    🚀 快速开始 安装 MkDocs 使用 pip 安装 MkDocs：

    bash pip install mkdocs 创建新项目 bash mkdocs new my-project cd my-project 预览文档 启动开发服务器：

    bash mkdocs serve 然后在浏览器中访问 http://localhost:8000

    构建站点 构建静态站点以进行部署：

    bash mkdocs build 这将在 site 目录中生成完整的静态网站。

    🎯 核心功能 简洁的配置 MkDocs 使用简单的 YAML 配置文件：

    yaml site_name: My Docs site_description: 我的项目文档 site_author: 您的姓名

    theme: name: material

    nav: - 首页: index.md - 指南: guide.md - API 参考: api.md

    plugins: - search 丰富的主题支持 MkDocs 支持多种主题：

    mkdocs - 默认主题，简洁清晰

    readthedocs - 仿 ReadTheDocs 风格

    material - Material Design 风格，功能丰富

    插件生态系统 扩展 MkDocs 功能：

    mkdocs-minify - 压缩 HTML、JS 和 CSS

    mkdocs-rss - 生成 RSS 订阅

    mkdocs-git-revision-date-localized - 显示页面最后更新时间

    mkdocs-redirects - 创建页面重定向

    📖 使用指南 编写内容 在 docs 目录中创建 Markdown 文件来编写您的文档内容。

    开发环境设置 bash git clone https://github.com/mkdocs/mkdocs.git cd mkdocs pip install -e . 📝 常见问题 如何添加自定义 CSS？ 在 mkdocs.yml 中添加：

    yaml extra_css: - stylesheets/extra.css 然后在 docs/stylesheets/extra.css 中编写自定义样式。

    如何支持多语言？ MkDocs 本身不直接支持多语言，但可以通过以下方式实现：

    为每种语言创建单独的目录

    使用插件如 mkdocs-static-i18n

    为每种语言配置单独的构建

    如何添加数学公式？ 使用 pymdownx.arithmatex 扩展：

    yaml markdown_extensions: - pymdownx.arithmatex: generic: true 然后在页面中使用 $$E = mc^2$$ 语法。
